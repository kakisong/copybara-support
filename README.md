# CopyBara 隐私政策 / Privacy Policy

**最后更新日期 / Last Updated:** 2026-11-21

---

## 简体中文

CopyBara 尊重并严格保护您的个人隐私。本应用采用「纯本地离线优先」架构设计：

1. **零云端数据收集**：您的所有剪贴板历史（文本、图片、文件路径）、离线 OCR 识别结果、置顶内容及自定义文本片段均 **100% 存储在您本地 Mac 设备的应用沙盒/数据目录中**。CopyBara 不设任何后台收集服务器，绝不会上传、出售或共享您的任何剪贴板或个人数据。
2. **敏感信息自动过滤**：CopyBara 默认自动忽略带有系统隐私/临时标记（如 `org.nspasteboard.ConcealedType`、`TransientType`）的剪贴板内容，默认跳过 1Password、Bitwarden、钥匙串访问及 Apple 密码等密码管理器数据，并支持您随时自定义忽略应用名单或一键清空记录。
3. **离线图像文字识别（OCR）**：图片中的中英文文字识别完全基于 macOS 内置的 Apple Vision 框架在设备本地离线完成，图片不会发送至任何外部网络。
4. **网络请求说明**：应用仅在检测版本更新（查询 Apple 官方 App Store 版本目录）或您主动点击「网页搜索 / 在浏览器中打开链接」时发起常规网络访问，不包含任何第三方广告 SDK、统计埋点或追踪器。

如有任何疑问，请通过开发者支持邮箱联系我们。

## English

CopyBara is built from the ground up with a strict **local-first, zero-telemetry** privacy architecture:

1. **No Data Collection or Cloud Sync**: Every clipboard history item (text, images, file references), OCR result, pinned entry, and custom snippet is stored **100% locally on your Mac**. CopyBara does not collect, transmit, store on external servers, or share any of your clipboard data or personal information.
2. **Password & Sensitive Data Protection**: CopyBara automatically ignores concealed and transient pasteboard items (such as entries from 1Password, Bitwarden, Keychain Access, and Apple Passwords) and lets you exclude any application or clear history at any time.
3. **100% On-Device OCR**: Screenshot and image text recognition runs locally on your Mac using Apple's built-in Vision framework. No images ever leave your device.
4. **Minimal Network Usage**: Network access is used solely to check Apple's official App Store catalog for version updates (when enabled) or when you explicitly open a URL or web search. CopyBara contains zero third-party analytics, trackers, or advertising SDKs.
