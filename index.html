CopyBara 技术支持 / Support

CopyBara 是一款专为 macOS 打造的原生剪贴板历史、离线截图 OCR、大爆炸分词与常用文本片段管理工具。

常用快捷键 / Default Shortcuts

  • 打开剪贴板历史面板：⌥⌘C (Option + Command + C)
  • 打开文本片段面板：⌥⌘S (Option + Command + S)
  • 大爆炸智能分词：在面板内按 ⌘B
  • 文本转换动作面板：在面板内按 ⌘K
